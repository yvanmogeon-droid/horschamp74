Il passe pour le plus pur d'Europe. Sauf que depuis des années, chaque averse charrie depuis les routes riveraines une substance que personne ne voit mais que les analyses commencent à débusquer : le 6PPD-quinone, un dérivé toxique issu de l'usure des pneus. Dans le lac d'Annecy, ce polluant — reconnu comme mortel pour certains salmonidés outre-Atlantique — s'accumule discrètement dans les sédiments et la colonne d'eau.
Le mécanisme est implacable : les pneus s'effritent sur l'asphalte, la pluie lessivée les emporte vers les fossés, les ruisseaux, le lac. Annecy n'est pas un cas isolé — tous les plans d'eau bordés de routes sont concernés — mais le paradoxe est brutal ici : on surveille les algues, on interdit les moteurs thermiques sur le lac, on filtre les eaux usées depuis les années 1960… et on laisse les voitures déposer tranquillement leurs cocktails chimiques à chaque virage.
La 6PPD-quinone n'est pas encore classée dans les réglementations européennes en vigueur. Elle n'est pas mesurée systématiquement dans les contrôles qualité du lac. Autrement dit : elle existe, elle se dépose, et officiellement elle n'est pas là.
Le lac le plus surveillé de France cache peut-être une pollution que personne n'a encore décidé de compter.
